<objective>
## Goal
Build the backend infrastructure for weekly auto-reanalysis: extract shared scraper logic into a service, add pharmacy URL registration to Supabase, and create automation endpoints that n8n Cloud will call to scrape each user's own pharmacy and save a new analysis.

## Purpose
Enables the Phase 4 automation loop — without these endpoints, n8n has nothing to call. This plan is pure backend; n8n workflow setup and email delivery are 04-02.

## Output
- `backend/services/scraper.py` — shared gosom + Outscraper logic (extracted from competitor.py)
- `backend/routers/automation.py` — user-facing pharmacy URL endpoints + n8n internal trigger endpoints
- `backend/routers/competitor.py` — updated to import from services.scraper (no API surface change)
- `backend/main.py` — automation router registered
- `render.yaml` — N8N_WEBHOOK_SECRET env var documented
</objective>

<acceptance_criteria>

## AC-1: Pharmacy URL Registration
```gherkin
Given an authenticated user with an active subscription and a valid Bearer token
When they PATCH /automation/pharmacy-url with {"url": "https://www.google.com/maps/place/..."}
Then 200 is returned and pharmacy_url is stored in their subscriptions row
And GET /automation/pharmacy-url returns that same URL
```

## AC-2: URL Validation
```gherkin
Given an authenticated premium user
When PATCH /automation/pharmacy-url is called with a URL that is not a Google Maps URL
Then 422 is returned with a validation error
```

## AC-3: Eligible Users List
```gherkin
Given multiple active subscribers, some with pharmacy_url set and some without
When GET /automation/eligible-users is called with the correct X-N8N-Secret header
Then only users with pharmacy_url IS NOT NULL are returned
And each entry contains {user_id, email, pharmacy_url}
```

## AC-4: Auto-Rerun Pipeline
```gherkin
Given a user_id with an active subscription and pharmacy_url set
When POST /automation/rerun/{user_id} is called with the correct X-N8N-Secret header
Then the pharmacy URL is scraped via gosom (Outscraper fallback if 502)
And VADER + narrative run on the scraped reviews
And a new row is inserted into the analyses table for that user
And {"user_id": ..., "analysis_id": ...} is returned
```

## AC-5: Internal Endpoint Security
```gherkin
Given a request to GET /automation/eligible-users or POST /automation/rerun/{user_id}
When the X-N8N-Secret header is missing or incorrect
Then 401 is returned
```

<task type="auto">
  <name>Task 3: n8n internal trigger endpoints + auto-rerun pipeline</name>
  <files>backend/routers/automation.py, render.yaml</files>
  <action>
    Add internal auth helper to automation.py:
    ```python
    def _verify_n8n_secret(request: Request):
        secret = os.getenv("N8N_WEBHOOK_SECRET", "")
        if not secret or request.headers.get("X-N8N-Secret") != secret:
            raise HTTPException(status_code=401, detail="Invalid or missing N8N secret")
    ```

    `GET /automation/eligible-users`:
    - Call `_verify_n8n_secret(request)` first
    - Query subscriptions: select user_id, pharmacy_url where status='active' AND pharmacy_url IS NOT NULL
    - For each row, fetch email via `supabase.auth.admin.get_user_by_id(user_id).user.email`
    - Return list: `[{"user_id": ..., "email": ..., "pharmacy_url": ...}]`
    - If auth.admin call fails for a user, skip that user (log warning, don't fail the whole batch)

    `POST /automation/rerun/{user_id}`:
    - Call `_verify_n8n_secret(request)` first
    - Fetch pharmacy_url from subscriptions for user_id (check status=active AND pharmacy_url IS NOT NULL; raise 404 if not found)
    - Call `await scrape_with_fallback(pharmacy_url)` — returns `{"name": ..., "reviews": [{"text": ..., "rating": ...}]}`
    - Build reviews list for sentiment pipeline (no date field → timeline will be empty, which is fine)
    - Run `run_sentiment_pipeline(reviews)` from services.sentiment
    - Run `generate_narrative(result)` from services.narrative — wrap in try/except; if narrative fails, proceed with narrative=None (non-blocking)
    - Save to analyses table using supabase.table("analyses").insert({...}) — same fields as analyses.py save_analysis
    - Return `{"user_id": user_id, "analysis_id": inserted_id}`

    Update `render.yaml` — add to the review-radar-api envVars block:
    ```yaml
      - key: N8N_WEBHOOK_SECRET
        sync: false
        # Shared secret between Render and n8n Cloud.
        # Set in both Render dashboard and n8n workflow HTTP node headers.
        # Generate: python -c "import secrets; print(secrets.token_urlsafe(32))"
    ```

    Avoid: using user JWT auth on these internal endpoints — n8n has no user session; use the shared secret pattern instead.
    Avoid: blocking the batch if one user's rerun fails — each rerun is independent.
  </action>
