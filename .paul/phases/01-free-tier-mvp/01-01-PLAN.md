## Goal
Bootstrap a Next.js 14 App Router + Tailwind frontend and a FastAPI Python backend with CORS configured, environment variables wired, and both services startable locally — ready for feature development in 01-02.

## Purpose
Every subsequent plan in Phase 1 builds on this scaffold. Getting the project structure, tooling, and inter-service communication right here prevents rework later. The frontend/backend split mirrors the production deployment (Netlify + Render).

## Output
- `frontend/` — Next.js 14 App Router project with Tailwind, TypeScript, placeholder home page
- `backend/` — FastAPI app with CORS, /health endpoint, requirements.txt, env config
- Both services start without errors and communicate locally
