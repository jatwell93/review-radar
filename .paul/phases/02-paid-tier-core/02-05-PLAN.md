<objective>
## Goal
Upgrade the narrative endpoint to include month-over-month trend commentary when a prior analysis exists, and upgrade the history page to display a side-by-side Latest vs Previous comparison card with score delta and distribution delta.

## Purpose
Phase 2 closes with this plan. Premium users now have a closed loop: they upload a CSV, their analysis is saved, and on their next upload the narrative tells them whether their sentiment has improved or declined. The history page gives them a visual snapshot of progress — turning raw data into ongoing operational insight.

    The full updated handleAnalysisSuccess:
    ```typescript
    async function handleAnalysisSuccess(data: AnalysisResponse) {
      setAnalysisResult(data);
      setNarrativeLoading(true);

      // Snapshot previous score before saving current (avoids race condition)
      const supabase = createClient();
      const { data: { session } } = await supabase.auth.getSession();
      let previousScore: number | null = null;
      let previousDistribution: { positive: number; neutral: number; negative: number } | null = null;
      if (session) {
        try {
          const { data: prev } = await supabase
            .from("analyses")
            .select("overall_score, distribution")
            .order("created_at", { ascending: false })
            .limit(1)
            .maybeSingle();
          if (prev) {
            previousScore = prev.overall_score;
            previousDistribution = prev.distribution as { positive: number; neutral: number; negative: number };
          }
        } catch {
          // Silent degradation — narrative still works without trend context
        }
      }

      trySaveAnalysis(data, null);
      tryFetchTopics(data); // no await — runs in parallel with narrative

      try {
        const narrativeRes = await fetch(`${API_URL}/narrative/`, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({
            ...data,
            previous_score: previousScore,
            previous_distribution: previousDistribution,
          }),
        });
        if (narrativeRes.ok) {
          const narrativeData: NarrativeResponse = await narrativeRes.json();
          setNarrative(narrativeData.narrative);
        }
        // Non-ok response: leave narrative null (graceful degradation)
      } catch {
        // Network failure: leave narrative null (graceful degradation)
      } finally {
        setNarrativeLoading(false);
      }
    }
    ```

    Supabase `getSession()` for unauthenticated users returns `session: null` immediately from local storage — no network call, no latency impact on free-tier users. For premium users with history, the additional `.from("analyses")` Supabase query adds ~100-200ms before the narrative request fires; the loading skeleton is already visible so UX is unaffected.
