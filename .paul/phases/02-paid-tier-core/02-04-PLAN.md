## Goal
Add KeyBERT topic extraction: a premium-gated POST /topics/ endpoint extracts the top positive and negative keyword themes from a user's reviews, displayed as tag pills in the ResultsDashboard.

## Purpose
KeyBERT topics are the paid-tier differentiator — moving beyond a single sentiment score to answer "what specifically are customers praising and complaining about?" This closes the core Phase 2 NLP feature and gives pharmacy owners actionable theme-level insight.

    1. Add import: `import type { ..., TopicsResponse } from "@/types/analysis";`

    2. Add state above existing state vars:
    ```typescript
    const [topics, setTopics] = useState<TopicsResponse | null>(null);
    const [topicsLoading, setTopicsLoading] = useState(false);
    const [topicsDenied, setTopicsDenied] = useState(false); // true when 401/403 = show upsell
    ```

    3. Add `tryFetchTopics` function after `trySaveAnalysis`:
    ```typescript
    async function tryFetchTopics(data: AnalysisResponse) {
      const supabase = createClient();
      const { data: { session } } = await supabase.auth.getSession();
      if (!session) {
        setTopicsDenied(true);
        return;
      }
      setTopicsLoading(true);
      try {
        const res = await fetch(`${API_URL}/topics/`, {
          method: "POST",
          headers: {
            "Content-Type": "application/json",
            Authorization: `Bearer ${session.access_token}`,
          },
          body: JSON.stringify({
            top_reviews: data.top_reviews,
            bottom_reviews: data.bottom_reviews,
          }),
        });
        if (res.ok) {
          const topicsData: TopicsResponse = await res.json();
          setTopics(topicsData);
        } else {
          setTopicsDenied(true); // 401 or 403 — not premium
        }
      } catch {
        // Network failure — degrade silently, show nothing (not upsell)
      } finally {
        setTopicsLoading(false);
      }
    }
    ```

    4. In `handleAnalysisSuccess`, call `tryFetchTopics(data)` after `trySaveAnalysis(data, null)` (fire-and-forget, no await):
    ```typescript
    async function handleAnalysisSuccess(data: AnalysisResponse) {
      setAnalysisResult(data);
      trySaveAnalysis(data, null);
      tryFetchTopics(data); // no await — runs in parallel with narrative
      setNarrativeLoading(true);
      // ... rest unchanged
    }
    ```

    5. In `handleReset`, clear topics state:
    ```typescript
    function handleReset() {
      setAnalysisResult(null);
      setNarrative(null);
      setNarrativeLoading(false);
      setTopics(null);
      setTopicsLoading(false);
      setTopicsDenied(false);
    }
    ```

    ```tsx
      narrativeLoading={narrativeLoading}
      topics={topics}
      topicsLoading={topicsLoading}
      topicsDenied={topicsDenied}
    />
    ```
