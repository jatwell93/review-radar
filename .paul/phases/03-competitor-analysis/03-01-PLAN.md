<acceptance_criteria>

## AC-1: Scrape Returns Review Data
```gherkin
Given a premium user with a valid JWT and a Google Maps place URL
When they POST to /competitor/scrape with {"url": "https://www.google.com/maps/place/..."}
Then the response is 200 JSON with {"name": str, "overall_rating": float, "reviews": [...]}
And each review in the array contains at minimum {"text": str, "rating": float}
```

## AC-2: Unauthenticated Request Rejected
```gherkin
Given a request with no Authorization header or an invalid token
When they POST to /competitor/scrape
Then the backend returns 401
```

## AC-3: Non-Premium User Rejected
```gherkin
Given a user with a valid JWT but no active subscription
When they POST to /competitor/scrape
Then the backend returns 403 with detail "premium_required"
```

## AC-4: Invalid URL Rejected
```gherkin
Given a premium user with a valid JWT
When they POST to /competitor/scrape with a non-Google-Maps URL
Then the backend returns 422 with a validation error
```

## AC-5: gosom Unreachable → Graceful Error
```gherkin
Given gosom service is down or GOSOM_API_URL is misconfigured
When a premium user POSTs to /competitor/scrape
Then the backend returns 502 with detail "scraper_unavailable"
And no unhandled exception is raised
```

## AC-6: Docker Service Builds and Starts
```gherkin
Given the gosom/ directory exists in the repo
When `docker build gosom/ -t gosom-test` is run locally
Then the build completes without error
And `docker run -p 8080:8080 gosom-test` starts without immediately exiting
```

## AC-7: Empty Reviews Handled Gracefully
<!-- audit-added: stabilises the contract for 03-03 gap analysis which depends on this response shape -->
```gherkin
Given a premium user submits a valid Google Maps URL
When gosom returns 0 reviews for that place (scraped successfully but no review data)
Then the endpoint returns 200 with {"name": str, "overall_rating": float, "reviews": []}
And does NOT return 500 or 502
```

    3. Request model with Google Maps URL validation:
       <!-- audit-added: Field(max_length=2000) prevents unbounded URL payload abuse; added Field import -->
       ```python
       from pydantic import BaseModel, Field, field_validator

       class CompetitorScrapeRequest(BaseModel):
           url: str = Field(max_length=2000)  # audit-added: browser URL practical max ~2000 chars

           @field_validator("url")
           @classmethod
           def must_be_google_maps_url(cls, v):
               if not (
                   v.startswith("https://www.google.com/maps")
                   or v.startswith("https://maps.google.com")
               ):
                   raise ValueError("URL must be a Google Maps place URL")
               return v
       ```

    4. Router definition: `router = APIRouter(prefix="/competitor", tags=["competitor"])`

    5. gosom call helper (async, with timeout):
       ```python
       _GOSOM_TIMEOUT = 120.0  # scraping multiple reviews takes time

       async def _call_gosom(url: str) -> dict:
           gosom_base = os.getenv("GOSOM_API_URL")
           # Check gosom server API docs for exact endpoint path and request body format.
           # Likely candidates (verify against gosom README --server docs):
           #   POST {gosom_base}/api/v1/scrape  with body {"url": url}
           #   POST {gosom_base}/scrape         with body {"urls": [url]}
           # Adjust the path and body key to match what gosom's server actually accepts.
           try:
               async with httpx.AsyncClient(timeout=_GOSOM_TIMEOUT) as client:
                   resp = await client.post(
                       f"{gosom_base}/api/v1/scrape",  # verify this path
                       json={"url": url},
                   )
                   resp.raise_for_status()
                   return resp.json()
           except Exception:
               raise HTTPException(status_code=502, detail="scraper_unavailable")
       ```

    6. POST /competitor/scrape endpoint:
       - Auth pattern exactly matching analyses.py (Bearer token → get_user → premium gate)
       - Call _call_gosom
       - Normalize response: map gosom's field names to {"name": str, "overall_rating": float, "reviews": list}
       - Check gosom docs for its exact JSON field names (likely: "title"/"name", "rating"/"averageRating",
         "reviews" array with "text"/"snippet" and "rating"/"stars")
       - If gosom returns no reviews: return {"name": ..., "overall_rating": ..., "reviews": []}
       - Each review in output: {"text": str, "rating": float} at minimum

       ```python
       @router.post("/scrape")
       async def scrape_competitor(request: Request, body: CompetitorScrapeRequest):
           # --- Auth ---
           auth_header = request.headers.get("Authorization", "")
           if not auth_header.startswith("Bearer "):
               raise HTTPException(status_code=401, detail="Missing or invalid Authorization header")
           token = auth_header.removeprefix("Bearer ").strip()

           supabase = _get_supabase_admin()
           try:
               user_response = supabase.auth.get_user(token)
               if not user_response or not user_response.user:
                   raise HTTPException(status_code=401, detail="Invalid or expired token")
               user = user_response.user
           except HTTPException:
               raise
           except Exception:
               raise HTTPException(status_code=401, detail="Invalid or expired token")

           # --- Premium gate ---
           sub_result = (
               supabase.table("subscriptions")
               .select("status")
               .eq("user_id", str(user.id))
               .limit(1)
               .execute()
           )
           sub_data = sub_result.data[0] if sub_result.data else None
           if not sub_data or sub_data.get("status") != "active":
               raise HTTPException(status_code=403, detail="premium_required")

           # --- Scrape ---
           raw = await _call_gosom(body.url)

           # Normalize to stable contract for downstream plans (03-02, 03-03)
           # Adjust field names below to match actual gosom response keys.
           # Wrap in try/except: if gosom returns an unexpected shape (list, missing keys,
           # non-numeric rating), return 502 rather than an unhandled 500.
           # <!-- audit-added: normalization failure on unexpected gosom response format was unhandled -->
           try:
               reviews = [
                   {"text": r.get("text", ""), "rating": float(r.get("rating", 0))}
                   for r in raw.get("reviews", [])
               ]
               return {
                   "name": raw.get("name", ""),
                   "overall_rating": float(raw.get("rating", 0)),
                   "reviews": reviews,
               }
           except Exception:
               raise HTTPException(status_code=502, detail="scraper_response_invalid")
       ```
