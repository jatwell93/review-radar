## AC-1: URL Input and Scrape Flow
```gherkin
Given a premium user is on /dashboard/competitor
When they enter a valid Google Maps URL and click "Analyse Competitor"
Then they see a loading state ("Scraping reviews…")
And when the scrape completes (up to ~3 min), they see the competitor's name, overall rating, and review list
```

## AC-2: Non-Premium Gate
```gherkin
Given a user with a valid JWT but no active subscription visits /dashboard/competitor
Then they see an upgrade prompt (not the URL input form)
And the upgrade prompt links back to /dashboard
```

## AC-3: Unauthenticated Redirect
```gherkin
Given an unauthenticated user visits /dashboard/competitor
Then they are redirected to /login
```

## AC-4: Invalid URL Error
```gherkin
Given a premium user enters a non-Google-Maps URL (or leaves the field empty) and submits
Then the form shows a validation error message ("Please enter a valid Google Maps place URL")
And does not call the backend
```

## AC-5: Scraper Error Handling
```gherkin
Given the backend returns 502 (scraper_unavailable) or any non-200 response
When the premium user submits a valid URL
Then the form shows a user-friendly error ("Could not reach the scraper — please try again shortly")
And the form remains usable (not frozen)
```

## AC-6: Dashboard Entry Point
```gherkin
Given a premium user is on /dashboard
When they look at the dashboard page
Then they see an "Analyse Competitor" link/button that navigates to /dashboard/competitor
```

## AC-7: Malformed Response Does Not Crash Component
<!-- audit-added: res.json() can throw SyntaxError on non-JSON body (e.g., HTML error page from Render) -->
```gherkin
Given the backend returns 200 but with a non-JSON response body
When a premium user submits a valid URL
Then the form shows "Unexpected response from server — please try again"
And the form remains usable (loading cleared, input re-enabled)
```

## AC-8: Frontend Timeout Prevents Indefinite Loading
<!-- audit-added: without AbortController, frontend hangs forever if gosom stalls beyond its own 180s poll ceiling -->
```gherkin
Given gosom takes longer than 4 minutes to respond
When a premium user submits a valid URL
Then the form shows "Scraper timed out — please try again" after ~4 minutes
And the form remains usable (loading cleared, input re-enabled)
```

<task type="auto">
  <name>Task 2: CompetitorAnalyser client component</name>
  <files>frontend/src/components/CompetitorAnalyser.tsx</files>
  <action>
    Create `frontend/src/components/CompetitorAnalyser.tsx` as a Client Component (`'use client'`).

    **State:**
    ```tsx
    const [url, setUrl] = useState('')
    const [loading, setLoading] = useState(false)
    const [error, setError] = useState<string | null>(null)
    const [result, setResult] = useState<ScrapeResult | null>(null)
    ```

    **Types:**
    ```tsx
    interface Review {
      text: string
      rating: number
    }
    interface ScrapeResult {
      name: string
      overall_rating: number
      reviews: Review[]
    }
    ```

    **Client-side auth — get session token:**
    ```tsx
    import { createClient } from '@/lib/supabase/client'
    // Inside handleSubmit:
    const supabase = createClient()
    const { data: { session } } = await supabase.auth.getSession()
    if (!session) {
      setError('Your session has expired. Please log in again.')
      return
    }
    const token = session.access_token
    ```

    **handleSubmit:**
    1. Validate URL client-side before calling backend:
       - Must start with `https://www.google.com/maps` or `https://maps.google.com`
       - If invalid: `setError('Please enter a valid Google Maps place URL')` and return (AC-4)
    2. `setLoading(true)`, `setError(null)`, `setResult(null)`
    3. <!-- audit-added: AbortController with 240s timeout prevents indefinite loading if gosom stalls past its own 180s ceiling -->
       Create an AbortController and schedule abort after 240 seconds:
       ```tsx
       const controller = new AbortController()
       const timer = setTimeout(() => controller.abort(), 240_000)
       ```
    4. POST to `${process.env.NEXT_PUBLIC_API_URL}/competitor/scrape` with:
       - `Content-Type: application/json`
       - `Authorization: Bearer ${token}`
       - `signal: controller.signal`
       - body: `JSON.stringify({ url })`
    5. If response not ok — set error and **return** immediately (do NOT fall through to json parse):
       - 422: `setError('Please enter a valid Google Maps place URL'); return`
       - 502 or any other: `setError('Could not reach the scraper — please try again shortly'); return`
       <!-- audit-added: explicit return prevents fall-through to res.json() on error response -->
    6. <!-- audit-added: res.json() throws SyntaxError on malformed/non-JSON response (HTML error page, empty body) — must catch -->
       Wrap JSON parse in try/catch:
       ```tsx
       try {
         const data = await res.json()
         setResult(data)
       } catch {
         setError('Unexpected response from server — please try again')
       }
       ```
    7. In catch block for the overall try (wrapping the fetch):
       - If `err.name === 'AbortError'`: `setError('Scraper timed out — please try again')`
       - Otherwise: `setError('Could not reach the scraper — please try again shortly')`
    8. Always in finally: `clearTimeout(timer)` then `setLoading(false)`

    **Render:**

    *Form:*
    ```tsx
    <form onSubmit={handleSubmit} className="bg-white rounded-2xl shadow-sm border border-slate-200 p-6 mb-6">
      <label className="block text-sm font-medium text-slate-700 mb-2">
        Competitor Google Maps URL
      </label>
      <input
        type="url"
        value={url}
        onChange={e => setUrl(e.target.value)}
        placeholder="https://www.google.com/maps/place/..."
        disabled={loading}
        className="w-full px-4 py-2.5 border border-slate-300 rounded-lg text-sm text-slate-800 placeholder-slate-400 focus:outline-none focus:ring-2 focus:ring-indigo-500 disabled:opacity-50 mb-4"
      />
      {error && (
        <p className="text-sm text-red-600 mb-4">{error}</p>
      )}
      <button
        type="submit"
        disabled={loading || !url.trim()}
        className="px-6 py-2.5 text-sm font-semibold text-white bg-indigo-600 rounded-lg hover:bg-indigo-700 disabled:opacity-50 disabled:cursor-not-allowed transition-colors"
      >
        {loading ? 'Scraping reviews…' : 'Analyse Competitor'}
      </button>
    </form>
    ```

    *Loading hint (shown only while loading):*
    ```tsx
    {loading && (
      <div className="bg-amber-50 border border-amber-200 rounded-xl p-4 text-sm text-amber-800 mb-6">
        Scraping reviews can take 1–3 minutes. Please keep this page open.
      </div>
    )}
    ```

    *Results (shown when result != null):*
    ```tsx
    {result && (
      <div className="bg-white rounded-2xl shadow-sm border border-slate-200 p-6">
        <h2 className="text-xl font-bold text-slate-800 mb-1">{result.name || 'Unknown'}</h2>
        <p className="text-slate-500 text-sm mb-4">
          Overall rating: <span className="font-semibold text-slate-700">{result.overall_rating.toFixed(1)} ★</span>
          {' · '}
          {result.reviews.length} review{result.reviews.length !== 1 ? 's' : ''} scraped
        </p>
        {result.reviews.length === 0 ? (
          <p className="text-slate-400 text-sm">No reviews were returned for this place.</p>
        ) : (
          <div className="space-y-3 max-h-96 overflow-y-auto">
            {result.reviews.map((r, i) => (
              <div key={i} className="border-b border-slate-100 pb-3 last:border-0">
                <p className="text-xs text-slate-400 mb-0.5">{'★'.repeat(Math.round(r.rating))} ({r.rating.toFixed(1)})</p>
                <p className="text-sm text-slate-700">{r.text || <em className="text-slate-400">No review text</em>}</p>
              </div>
            ))}
          </div>
        )}
      </div>
    )}
    ```

    Avoid:
    - Storing the session token in component state between renders
    - Calling `getSession()` outside of the submit handler
    - Using Server Actions (this must be a Client Component for interactive results display)
    - Hardcoding the API URL (always use `process.env.NEXT_PUBLIC_API_URL`)
  </action>
