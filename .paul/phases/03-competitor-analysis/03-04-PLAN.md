<objective>
## Goal
Add Outscraper as a transparent fallback scraper: when gosom returns 502, automatically retry via the Outscraper Maps Reviews API if `OUTSCRAPER_API_KEY` is set — returning the same `{name, overall_rating, reviews[]}` contract to callers.

## Purpose
gosom can be blocked by Google anti-scraping measures. Without a fallback the whole competitor feature goes dark. Outscraper provides a commercial Google Maps reviews API (synchronous, JSON) that covers gaps without any UI change — the frontend is unaffected.

## Output
- `_call_outscraper(url, api_key)` async helper in `competitor.py`
- `_scrape_with_fallback(url)` orchestrator (gosom → Outscraper)
- `scrape_competitor` endpoint uses `_scrape_with_fallback` instead of raw gosom call
- `OUTSCRAPER_API_KEY` documented as optional sync:false env var in `render.yaml`
</objective>

<acceptance_criteria>

## AC-1: Fallback activates on gosom failure
```gherkin
Given OUTSCRAPER_API_KEY is configured and gosom is unreachable
When POST /competitor/scrape is called with a valid Google Maps URL
Then the endpoint returns 200 with {name, overall_rating, reviews[]} from Outscraper
```

## AC-2: No fallback when key absent
```gherkin
Given OUTSCRAPER_API_KEY is not set in the environment
When gosom returns a 502 error
Then the endpoint returns 502 "scraper_unavailable" (original error propagated)
```

## AC-3: Both scrapers fail
```gherkin
Given gosom is unavailable and Outscraper returns a non-200 response
When POST /competitor/scrape is called
Then the endpoint returns 502 "scraper_unavailable"
```

## AC-4: Response contract identical
```gherkin
Given Outscraper returns a valid JSON response
When _call_outscraper normalises it
Then the dict shape matches {name: str, overall_rating: float, reviews: [{text: str, rating: float}]}
  — identical to what _parse_gosom_csv returns
```

## AC-5: Non-502 gosom errors bypass fallback
```gherkin
Given gosom returns a 401 or 422 (auth/validation error, not an availability problem)
When _scrape_with_fallback handles the exception
Then it re-raises without attempting Outscraper
```

      try:

          raise  # re-raise internal HTTPExceptions (e.g., non-200 status) unchanged
      except Exception:
          raise HTTPException(status_code=502, detail="scraper_unavailable")

    **`async def _scrape_with_fallback(url: str) -> dict`**
    - Step 1: try gosom
      ```python
      try:
          csv_text = await _call_gosom(url)
          return _parse_gosom_csv(csv_text)
      except HTTPException as exc:
          if exc.status_code != 502:
              raise  # auth/validation errors — not an availability problem (AC-5)
      except Exception:
          raise HTTPException(status_code=502, detail="scraper_response_invalid")
      ```
    - Step 2: gosom returned 502 — attempt Outscraper
      ```python
      outscraper_key = os.getenv("OUTSCRAPER_API_KEY")
      if not outscraper_key:
          raise HTTPException(status_code=502, detail="scraper_unavailable")  # AC-2
      # audit-added: log fallback activation for cost monitoring and gosom blockage detection
      logger.warning("gosom unavailable (502), falling back to Outscraper for %s", url)
      return await _call_outscraper(url, outscraper_key)
      ```
